# Experimental Results

This folder contains the results of Student 1's DistilBERT baseline and Learning Rate experiments.

## Learning Rate Experiments

Four Learning Rates were evaluated:

- 1e-5
- 2e-5 (Baseline)
- 5e-5
- 1e-4

## Best Configuration

The best validation performance was obtained with a Learning Rate of 1e-4.

## Final Test Performance

- Accuracy: 88.28%
- F1-score: 88.27%

All training runs were completed within the 10-minute limit.
